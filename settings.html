진행상태 목록 관리
"진행상태" 드롭다운에 표시될 항목입니다. 채용진행 중·신입교육·정착교육·팀 배치 완료는 자동화 로직과 연결되어 있어 삭제할 수 없어요.
데이터 저장 방식
모든 데이터는 이 브라우저의 LocalStorage에 저장되며, 새로고침·재접속해도 유지됩니다. 다른 브라우저·기기와는 공유되지 않아요.
데이터 백업 / 복원
브라우저 데이터를 JSON 파일로 내보내거나, 백업 파일을 다시 불러올 수 있어요.
위험 구역
전체 데이터(교사·평가·평가자)를 초기화합니다. 되돌릴 수 없어요.
